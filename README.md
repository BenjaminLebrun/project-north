# Project North

An open-source numerology research engine written in Python.

## Features

- Expression Number
- Soul Number
- Personality Number
- Life Path Number
- Interpretation Engine
- CLI
- JSON Export
- Markdown Export

## Installation

```bash
git clone <repository>

cd project-north

make install
```

## Usage

```bash
make run
```

or

```bash
python src/project_north/cli/main.py "Benjamin Lebrun" 12 11 1997
```

## Tests

```bash
make test
```

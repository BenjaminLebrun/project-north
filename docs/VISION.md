# Project North

## Vision

Project North est un framework open source d'analyse identitaire.

Son objectif est de permettre à toute personne d'explorer la cohérence entre l'identité qu'elle choisit de construire et différents systèmes symboliques, sans jamais présenter ces systèmes comme des vérités absolues.

Le projet repose sur quatre principes :

- Transparence
- Reproductibilité
- Documentation
- Personnalisation

Chaque résultat doit être :

- explicable ;
- vérifiable ;
- configurable ;
- reproductible.

Project North ne cherche pas à prédire l'avenir.

Il aide l'utilisateur à réfléchir à la cohérence entre ses valeurs, sa constitution personnelle, ses objectifs et les modèles symboliques qu'il choisit d'utiliser.

La première implémentation sera basée sur la numérologie pythagoricienne.

À long terme, le framework pourra accueillir d'autres systèmes d'analyse identitaire.

---

## Vision à long terme

Créer le framework open source de référence pour l'analyse identitaire symbolique.

Chaque modèle devra être indépendant, documenté et interchangeable.

L'utilisateur reste toujours libre de choisir les modèles qu'il souhaite utiliser.

Le logiciel n'impose jamais une vérité.

Il expose un raisonnement.

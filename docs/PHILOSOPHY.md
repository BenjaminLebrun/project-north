# Philosophy

## Core Principle

Project North is an identity framework.

Numerology is not the purpose of the project.

It is one possible language used to explore identity.

Every model integrated into Project North must satisfy the following principles.

---

## Principle 1 — Identity before prediction

The project never attempts to predict the future.

It evaluates coherence.

---

## Principle 2 — Transparency

Every calculation must be explainable.

No hidden algorithm.

No magic score.

Every result must expose:

- inputs;
- formulas;
- intermediate calculations;
- assumptions.

---

## Principle 3 — Modularity

Every symbolic system is independent.

Examples:

- Pythagorean Numerology
- Chaldean Numerology
- Name Symbolism
- Archetypes
- Personal Values

Each module can be enabled or disabled without affecting the others.

---

## Principle 4 — Scientific methodology

The framework documents hypotheses.

It does not claim they are objectively true.

Every implemented model must contain:

- references;
- bibliography;
- assumptions;
- known limitations.

---

## Principle 5 — User sovereignty

The user always remains responsible for decisions.

Project North provides analysis.

It never replaces judgment.

---

## Principle 6 — Open Source

Everything should be auditable.

Calculations.

Weights.

Datasets.

Documentation.

Tests.

---

## Principle 7 — Evolution

The project is designed to evolve.

Every module can be improved.

Every scoring model can be replaced.

Every formula can be versioned.

Backward compatibility should be preserved whenever possible.

---

## Motto

Build Identity.
Not Destiny.
